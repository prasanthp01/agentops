# Changelog

## 0.1.3 — 2026-10-13

Public source release under MIT. Adds configurable deployment origins, secure-cookie validation, public and private API boundary tests, a portable Docker quick start, source hygiene checks, licensed assets and usage documentation. Routing, budget accounting, recovery and mock-provider behavior remain explicit and deterministic.

## 0.1.0 — 2026-10-13

Initial deterministic routing engine, transactional budgets, attempt ledger, durable jobs, scoped APIs, editable simulator and independent routing evaluation corpus. Real-provider inference remains outside the released runtime.
