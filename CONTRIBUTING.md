# Contributing

Run the locked local setup and verification commands in README.md. Changes to policy filters, fallback, reservations, ownership or recovery must include behavioral regression coverage. Keep original package schemas intact; publish incompatible API changes with a new version. Generated contracts must match the application. Golden corpus expectations must remain independent of runtime routing decisions.

Do not add real data, credentials, customer logs, photos, remote telemetry, provider spend or shared-deployment changes. A pull request should explain observable behavior, validation and remaining limitations. Do not mark a placeholder integration or model adapter as connected. Contributions are distributed under the MIT license; retain all required third-party notices.
